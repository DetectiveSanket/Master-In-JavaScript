 🔹 ⁡⁢⁣⁣𝟭. 𝗪𝗵𝗮𝘁 𝗶𝘀 𝗮𝗻 𝗘𝘃𝗲𝗻𝘁?⁡

   - ⁡⁣⁣⁢𝗜𝗻 𝗝𝗮𝘃𝗮𝗦𝗰𝗿𝗶𝗽𝘁, 𝗮𝗻 𝗲𝘃𝗲𝗻𝘁 𝗶𝘀 𝘀𝗼𝗺𝗲𝘁𝗵𝗶𝗻𝗴 𝘁𝗵𝗮𝘁 𝗵𝗮𝗽𝗽𝗲𝗻𝘀 𝗶𝗻 𝘁𝗵𝗲 𝗯𝗿𝗼𝘄𝘀𝗲𝗿⁡.

    ## ✅ Common Examples of Events
        - 🖱️ User clicks a button
        - ⌨️ User types in an input field
        - 🖱️ User moves the mouse
        - 📩 User submits a form

    - So when a user clicks on an element, JavaScript can detect that action.

        ## Example:
        ⁡⁢⁢⁢button.addEventListener("click", function () {
            console.log("Button clicked");
        });⁡



    - When the button is clicked, JavaScript runs the given function.

----------------------------------------

 🔹 ⁡⁢⁣⁣𝟮. 𝗛𝗧𝗠𝗟 𝗘𝗹𝗲𝗺𝗲𝗻𝘁𝘀 𝗔𝗿𝗲 𝗜𝗻𝘀𝗶𝗱𝗲 𝗘𝗮𝗰𝗵 𝗢𝘁𝗵𝗲𝗿⁡

    - On a webpage, elements are usually nested.

    ## Example:
        ⁡⁢⁢⁢<div id="grandparent">
            <div id="parent">
                <button id="child">Click Me</button>
            </div>
        </div>⁡


    ## Structure:
        - `grandparent` → outer element
        - `parent` → inside grandparent
        - `child` → inside parent

    ### Visual Flow:

        grandparent
          ↓
        parent
          ↓
        child

    ## Important Point:
        If you click the button, the browser knows:
        - you clicked the button
        - the button is inside `parent`
        - the `parent` is inside `grandparent`

    - This is exactly where **event bubbling** and **event capturing** happen.

----------------------------------------

# 🔥 ⁡⁢⁣⁣𝟯. 𝗘𝘃𝗲𝗻𝘁 𝗕𝘂𝗯𝗯𝗹𝗶𝗻𝗴⁡

## ✅ Simple Definition
    - ⁡⁣⁣⁢When an event happens on a child element, it first runs on that child, then moves upward to the parent, and then upward again.⁡

    - This upward movement is called event bubbling.

    ## 🧠 Easy Line to Remember
        > **Bubbling means event goes from inside to outside.**

    ### Direction:
    `child -> parent -> grandparent`

    ### Phase Map (Bubbling)
    ```text
        Target (child)
        ↑
        Parent
        ↑
        Grandparent
    ```

    ## Example of Event Bubbling

    ### HTML:
    ```html
        <div id="grandparent">
        Grandparent
            <div id="parent">
                Parent
                <button id="child">Click Me</button>
            </div>
        </div>
    ```

    ### JavaScript:
    ```javascript
        document.getElementById("grandparent").addEventListener("click", function () {
            console.log("Grandparent clicked");
        });

        document.getElementById("parent").addEventListener("click", function () {
            console.log("Parent clicked");
        });

        document.getElementById("child").addEventListener("click", function () {
            console.log("Child clicked");
        });
    ```

    ## 📌 Output When Button is Clicked:
    ```javascript
        Child clicked
        Parent clicked
        Grandparent clicked
    ```

    ## 🤔 Why?
        - Because the click starts on the actual clicked element (`child`) and then travels upward.

    ✅ That is **event bubbling**.

----------------------------------------

# 🎯 ⁡⁢⁣⁣𝟰. 𝗘𝘃𝗲𝗻𝘁 𝗖𝗮𝗽𝘁𝘂𝗿𝗶𝗻𝗴⁡

    - ⁡⁣⁣⁢Capturing is the opposite of bubbling.⁡

    - ⁡⁣⁣⁢In capturing, the event starts from the outer element and moves inward to the target element.⁡

## 🧠 Easy Line to Remember
    > **Capturing means event goes from outside to inside.**

### Direction:
`grandparent -> parent -> child`

### Phase Map (Capturing)
```text
Grandparent
   ↓
Parent
   ↓
Target (child)
```

## Example of Event Capturing

To use capturing, pass `true` as the third argument in `addEventListener()`.

### JavaScript:
```javascript
        document.getElementById("grandparent").addEventListener(
            "click",
            function () {
                console.log("Grandparent clicked");
            },
            true
        );

        document.getElementById("parent").addEventListener(
            "click",
            function () {
                console.log("Parent clicked");
            },
            true
        );

        document.getElementById("child").addEventListener(
            "click",
            function () {
                console.log("Child clicked");
            },
            true
        );
```

## 📌 Output When Button is Clicked:
```javascript
    Grandparent clicked
    Parent clicked
    Child clicked
```

## 🤔 Why?
    - Because now the event travels from outer to inner.

✅ That is **event capturing**.

----------------------------------------

# 📦 5. Very Simple Real-Life Analogy

Imagine 3 boxes:

- 📦 Big box = `grandparent`
- 📦 Medium box = `parent`
- 📦 Small box = `child`

And you touch the smallest box.

## Bubbling:
The message goes:

- small box
- medium box
- big box

### Flow:
`small -> medium -> big`

## Capturing:
The message goes:

- big box
- medium box
- small box

### Flow:
`big -> medium -> small`

----------------------------------------

# ⚙️ 6. Default Behavior

B⁡⁣⁣⁢y default, JavaScript uses event bubbling.⁡

## Default Syntax:
```javascript
element.addEventListener("click", handler);
```

This works in the **bubbling phase**.

## Capturing Syntax:
```javascript
element.addEventListener("click", handler, true);
```

This works in the **capturing phase**.

## HTML:
```html
<div id="outer" style="padding: 30px; background: lightblue;">
  Outer Div
  <div id="inner" style="padding: 30px; background: lightgreen;">
    Inner Div

  </div>
```

```javascript
document.getElementById("outer").addEventListener("click", function () {

document.getElementById("inner").addEventListener("click", function () {
  console.log("Inner Div");
});

document.getElementById("btn").addEventListener("click", function () {
```

```javascript

Inner Div

```

```javascript
document.getElementById("outer").addEventListener("click", function () {
  console.log("Outer Div");

document.getElementById("inner").addEventListener("click", function () {
  console.log("Inner Div");
}, true);

document.getElementById("btn").addEventListener("click", function () {
  console.log("Button");
}, true);
```

### Output when button is clicked:
```javascript
Outer Div
Inner Div
Button
```

# ✋ ⁡⁢⁣⁣𝟴. 𝘀𝘁𝗼𝗽𝗣𝗿𝗼𝗽𝗮𝗴𝗮𝘁𝗶𝗼𝗻()⁡

Sometimes you do **not** want the event to continue moving.

For that, JavaScript provides:

```javascript
    event.stopPropagation();
```

## Example:
```javascript
    document.getElementById("parent").addEventListener("click", function () {
        console.log("Parent clicked");
    });

    document.getElementById("child").addEventListener("click", function (event) {
        console.log("Child clicked");
        event.stopPropagation();
    });
```

## Output:
```javascript
    Child clicked
```

## Why did parent not run?
    - Because `stopPropagation()` stops the event from moving further.

✅ It can stop bubbling or capturing from continuing.

# 🎤 ⁡⁢⁣⁣𝟵. 𝗜𝗻𝘁𝗲𝗿𝘃𝗶𝗲𝘄-𝗦𝘁𝘆𝗹𝗲 𝗦𝗵𝗼𝗿𝘁 𝗗𝗲𝗳𝗶𝗻𝗶𝘁𝗶𝗼𝗻⁡

##⁡⁣⁢⁣ Event Bubbling⁡ :- 
    - Event bubbling is a process where an event starts from the target element and then propagates upward to its parent and ancestors.

##⁡⁣⁢⁣ 𝗘𝘃𝗲𝗻𝘁 𝗖𝗮𝗽𝘁𝘂𝗿𝗶𝗻𝗴⁡ :-
    - Event capturing is a process where an event starts from the top ancestor and propagates downward to the target element.

----------------------------------------

# 📊 10. Difference Between Bubbling and Capturing

| Feature | Event Bubbling | Event Capturing |
|--------|-----------------|-----------------|
| Direction | Child → Parent | Parent → Child |
| Movement | Inside → Outside | Outside → Inside |
| Default in JavaScript? | ✅ Yes | ❌ No |
| Setup | Normal `addEventListener()` | Use `true` as 3rd argument |
| Usage | More common | Less common |

----------------------------------------

# 🧠 11. One-Line Memory Trick

    - Bubbling = bottom to top
    - Capturing = top to bottom
    
----------------------------------------

# ✅ 12. Final Simple Summary

When you click an element inside other elements, the event can travel in **two ways**:

## 1. Event Capturing
`outer -> inner`

## 2. Event Bubbling
`inner -> outer`

----------------------------------------

# ⚠️ 13. Common Mistakes

- ❌ Forgetting that bubbling is the default
- ❌ Thinking `true` turns bubbling on (it actually turns **capturing** on)
- ❌ Using `stopPropagation()` and wondering why parent handlers do not fire

----------------------------------------
