

================================================================================
🌟 `JSON.stringify()` AND `JSON.parse()` 🌟
================================================================================
    These methods are all about converting between JavaScript values and JSON text.

--------------------------------------------------------------------------------
🔥 1) FIRST CLEAR IDEA
--------------------------------------------------------------------------------
    Think of it like this:

    🔹 JavaScript value  -> `JSON.stringify(...)` -> JSON string
    🔹 JSON string       -> `JSON.parse(...)`     -> JavaScript value

    That JavaScript value can be:
    ✔️ object
    ✔️ array
    ✔️ string
    ✔️ number
    ✔️ boolean
    ✔️ `null`

    💡 Note: `JSON.parse()` does not only return objects/arrays. It can return other values too.


--------------------------------------------------------------------------------
🤔 2) WHAT IS JSON?
--------------------------------------------------------------------------------
    JSON means JavaScript Object Notation.

    It looks similar to JavaScript objects, but JSON is actually just text with strict rules.

    Example JSON text:
    `{"name":"sanket","age":21}`

    ⚠️ This is not an object by itself. It is a string of text unless you parse it.


--------------------------------------------------------------------------------
🛠️ 3) WHAT `JSON.stringify()` DOES
--------------------------------------------------------------------------------
    `JSON.stringify(value)` takes a JavaScript value and returns a string in JSON format.

    📌 Example with object:
    let obj1 = {
      name: "sanket",
      age: 21,
      city: "pune",
    };

    let stringfly = JSON.stringify(obj1);

    console.log(stringfly);        // {"name":"sanket","age":21,"city":"pune"}
    console.log(typeof stringfly); // string

    So yes:
- before stringify -> object
- after stringify  -> string

    That means now you can use string methods:
    console.log(stringfly.length);
    console.log(stringfly.includes("sanket"));
    console.log(stringfly.toUpperCase());

    🚫 But you cannot use object-style access meaningfully unless you parse it back:
    console.log(stringfly.name); // undefined
    Because it is now just a string, not an object.


--------------------------------------------------------------------------------
🔄 4) WHAT `JSON.parse()` DOES
--------------------------------------------------------------------------------
    `JSON.parse(jsonString)` takes a valid JSON string and converts it back into a JavaScript value.

    📌 Example:
    let str = '{"name":"sanket","age":21,"city":"pune"}';
    let obj = JSON.parse(str);

    console.log(obj);        // { name: 'sanket', age: 21, city: 'pune' }
    console.log(typeof obj); // object
    console.log(obj.name);   // sanket

    ✅ Now it is an object again, so object access works.


--------------------------------------------------------------------------------
⚠️ 5) IMPORTANT: `JSON.parse()` CAN RETURN MORE THAN OBJECT/ARRAY
--------------------------------------------------------------------------------
    A lot of learners think parse only returns objects or arrays. Not true!

    🔹 Parse object
    JSON.parse('{"a":1}')   // { a: 1 }

    🔹 Parse array
    JSON.parse('[1,2,3]')   // [1, 2, 3]

    🔹 Parse string
    JSON.parse('"hello"')   // "hello"

    🔹 Parse number
    JSON.parse('123')       // 123

    🔹 Parse boolean
    JSON.parse('true')      // true

    🔹 Parse null
    JSON.parse('null')      // null

    🎯 Conclusion: `JSON.parse()` returns whatever that JSON text represents.


--------------------------------------------------------------------------------
📦 6) WHAT TYPES CAN `JSON.stringify()` HANDLE?
--------------------------------------------------------------------------------
    These are the normal JSON-supported types:
    ✔️ object
    ✔️ array
    ✔️ string
    ✔️ number
    ✔️ boolean
    ✔️ `null`

    📌 Examples:
    JSON.stringify({ a: 1 })   // '{"a":1}'
    JSON.stringify([1, 2, 3])  // '[1,2,3]'
    JSON.stringify("hello")    // '"hello"'
    JSON.stringify(100)        // '100'
    JSON.stringify(true)       // 'true'
    JSON.stringify(null)       // 'null'

    👀 Notice this carefully:             JSON.stringify("hello")
             returns: `'"hello"'`

    ❓ Why? Because the result must be a JSON string, and JSON strings include quotes.


--------------------------------------------------------------------------------
🧩 7) ARRAYS AND OBJECTS: HOW THEY BEHAVE
--------------------------------------------------------------------------------
    🔹 Object -> stringify
         let user = { name: "Sanket", age: 21 };
         let s = JSON.stringify(user);

     console.log(s); // {"name":"Sanket","age":21}
     console.log(typeof s); // string

    🔹 Array -> stringify
        let arr = [1, 2, 3, 4, 5];
        let s = JSON.stringify(arr);

        console.log(s); // [1,2,3,4,5]
        console.log(typeof s); // string
     - So even though it looks like an array in text form, it is still a string.

    🔹 Parse back
         let arr2 = JSON.parse(s);

         console.log(arr2); // [1, 2, 3, 4, 5]
         console.log(typeof arr2); // object
         console.log(Array.isArray(arr2)); // true

    ❗ Important point:
         typeof [] // "object"

     So for arrays, use:

         Array.isArray(arr2)

     because `typeof` is not enough.


--------------------------------------------------------------------------------
🚨 8) YOUR CODE: VERY IMPORTANT CLARIFICATION
--------------------------------------------------------------------------------
    You wrote:
    let arrayString = [...stringfly];
    let arrayString1 = {...stringfly};
    ⚠️ These are not JSON operations. These are spread operations on a string.

    🛑 `...[string]`
    let arrayString = [...stringfly];
    This creates an array of characters.

    Example:
    JSON.stringify({a:1}) // '{"a":1}'
    [...'{"a":1}']
    // ['{', '"', 'a', '"', ':', '1', '}']
    So this is not converting JSON string into an object/array in the JSON sense.
    It is just splitting the string into characters.

    🛑 `{...stringfly}`
    let arrayString1 = { ...stringfly };
    This creates an object whose keys are indexes and values are characters.

    Example:
    { ..."abc" }
    // {0: 'a', 1: 'b', 2: 'c'}
    So if `stringfly` is `'{"name":"sanket"}'`, then:
    { ...stringfly }
    becomes something like:
    {
      0: '{',
      1: '"',
      2: 'n',
      3: 'a',
      // ...
    }
    ❌ This is not the original object.
    It is just an object made from the string’s characters.

    ✅ To get the original object back, use:
    JSON.parse(stringfly)
    not spread syntax.


--------------------------------------------------------------------------------
✔️ 9) YOUR UNDERSTANDING ABOUT METHODS IS CORRECT
--------------------------------------------------------------------------------
    You said:
    "once that string is created, we can perform string methods on it, right? We can’t perform object methods on the string produced by JSON.stringify."

    🎯 That is correct!

    📌 Example:
    let obj = { name: "sanket" };
    let s = JSON.stringify(obj);

    console.log(typeof s);        // string
    console.log(s.toUpperCase()); // works
    console.log(s.length);        // works

    console.log(s.name);          // undefined

    If you want object behavior again:
    let back = JSON.parse(s);
    console.log(back.name); // sanket


--------------------------------------------------------------------------------
☠️ 10) VERY IMPORTANT: `JSON.stringify()` DOES NOT SAFELY CONVERT "ANYTHING"
--------------------------------------------------------------------------------
        - This is where most confusion happens. It does not mean literally everything works perfectly. Some values are handled strangely.

            A) `undefined`

            In object:
                JSON.stringify({ a: 1, b: undefined }) // '{"a":1}'
                (`undefined` property is removed.)

            In array:
                JSON.stringify([1, undefined, 3]) // '[1,null,3]'
                - (In arrays, `undefined` becomes `null`.)

            B) function

                In object:
                    JSON.stringify({ a: 1, fn: function() {} }) // '{"a":1}'
                    - (Function is omitted.)

                In array:
                    JSON.stringify([1, function() {}, 3]) // '[1,null,3]'

            C) symbol
                Similar behavior:
                - omitted in objects
                - becomes `null` in arrays

            D) `NaN`, `Infinity`, `-Infinity`
                JSON.stringify({ x: NaN, y: Infinity }) // '{"x":null,"y":null}'
                - (They become `null`.)

            E) `Date`
                let d = new Date();
                JSON.stringify(d)
                - This becomes a string, usually ISO format:
                `'"2026-04-20T08:00:00.000Z"'`

    If a `Date` is inside an object:
    JSON.stringify({ today: new Date() })
    Result: `'{"today":"2026-04-20T08:00:00.000Z"}'`
    After parsing, that `today` is a string, not a `Date` object.

        F) `BigInt`
                JSON.stringify(10n)
    ❌ This throws an error. `BigInt` is not directly supported by JSON.

        G) Circular reference
                let obj = {};
    obj.self = obj;

    JSON.stringify(obj); // Error
    ❌ This throws because JSON cannot represent circular references.


--------------------------------------------------------------------------------
📜 11) JSON HAS ITS OWN STRICT RULES
--------------------------------------------------------------------------------
    This matters a lot when using `JSON.parse()`.

    ✅ Valid JSON:
    `'{"name":"sanket","age":21}'`

    ❌ Invalid JSON:
    `"{name:'sanket', age:21}"`

    ❓ Why invalid?
        Because JSON rules require:
            - keys in double quotes
            - string values in double quotes
            - no comments
            - no trailing commas

    So this works:
        - JSON.parse('{"name":"sanket"}')

    This fails:
        - JSON.parse("{name:'sanket'}")


--------------------------------------------------------------------------------
💡 12) DIFFERENCE BETWEEN JAVASCRIPT OBJECT LITERAL AND JSON TEXT
--------------------------------------------------------------------------------
    This is one of the biggest concepts.

    🔹 JavaScript object:
        let obj = { name: "sanket" }; // type is : object
        - This is an actual JS object in memory.

    🔹 JSON string:
        let str = '{"name":"sanket"}'; // type is : string
        - This is just a string of text that looks like an object.
        - This is just a string.

    - They may look similar, but they are not the same thing.


--------------------------------------------------------------------------------
⚙️ 13) COMMON PATTERN
--------------------------------------------------------------------------------
    📥 Convert object to string:
        - let user = { name: "Sanket", age: 21 };
        - let json = JSON.stringify(user);

    💾 Store or send it:
        - localStorage
        - API request body
        - file
        - database field

    📤 Read it back:
        - let userAgain = JSON.parse(json);


--------------------------------------------------------------------------------
🌐 14) WHY DO WE EVEN USE JSON?
--------------------------------------------------------------------------------
    Mostly for:

    1️⃣ Sending data between frontend and backend:

      ⁡⁢⁢⁢  fetch("/api", {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify({ name: "Sanket" })
        });⁡

    2️⃣ Saving data in localStorage:
        - `localStorage` stores strings only.
            - let user = { name: "Sanket", age: 21 };
            - localStorage.setItem("user", JSON.stringify(user));

    let saved = JSON.parse(localStorage.getItem("user"));
    console.log(saved.name);

    3️⃣ Reading JSON files / API responses.


--------------------------------------------------------------------------------
🎭 15) DEEP COPY USING JSON? YES, BUT WITH LIMITS
--------------------------------------------------------------------------------
    Some people do this:
    let copy = JSON.parse(JSON.stringify(obj));
    It creates a new copied object for simple data.

    ⚠️ But it is not a perfect deep copy.
    It breaks or changes things like:
- functions
- `undefined`
- `Date`
- `Map`
- `Set`
- `BigInt`
- circular references

    So this trick is okay only for simple plain data.


--------------------------------------------------------------------------------
📊 16) VERY USEFUL TABLE
--------------------------------------------------------------------------------
    | Value | `JSON.stringify(value)` result | `JSON.parse(...)` gives back |
    |---|---|---|
    | `{a:1}` | `'{"a":1}'` | object |
    | `[1,2,3]` | `'[1,2,3]'` | array |
    | `"hello"` | `'"hello"'` | string |
    | `123` | `'123'` | number |
    | `true` | `'true'` | boolean |
    | `null` | `'null'` | `null` |
    | `undefined` | `undefined` or omitted/null depending on position | not valid directly |
    | function | omitted/null | not supported |
    | symbol | omitted/null | not supported |
    | `NaN` | `'null'` | `null` |
    | `Infinity` | `'null'` | `null` |
    | `new Date()` | JSON string date | string after parse |
    | `10n` | error | not supported |

--------------------------------------------------------------------------------
🧠 18) FINAL MENTAL MODEL
--------------------------------------------------------------------------------
    ✅ `JSON.stringify(value)`
- Takes a JavaScript value
- Produces a JSON-formatted string
- After this, it is just a string
- Use string methods on it

    ✅ `JSON.parse(jsonString)`
- Takes a valid JSON string
- Produces the corresponding JavaScript value
- That result may be object, array, string, number, boolean, or `null`


--------------------------------------------------------------------------------
📝 19) ONE-LINE SUMMARY
--------------------------------------------------------------------------------
- `JSON.stringify()` = JS value -> JSON string
- `JSON.parse()`     = JSON string -> JS value
- After stringify, the result is a string, not the original object/array
- To get object/array/value back, use `JSON.parse()`
- Not every JS value is fully supported by JSON

    💡 If you compare only your exact confusion in one sentence:
    `JSON.stringify(obj)` does not create a "special object-string"; it creates a normal string containing JSON text, and `JSON.parse()` turns that text back into the corresponding JavaScript value.
