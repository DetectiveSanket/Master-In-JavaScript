

## ⁡⁢⁣⁣𝗠𝗮𝗶𝗻 𝗰𝗼𝗻𝗰𝗲𝗽𝘁 𝗶𝗻 𝗮𝗿𝗿𝗮𝘆⁡

    ><⁡⁣⁢⁣ The six falsy values in JavaScript are:⁡ false, 0, "", null, undefined, and NaN.
    >< ⁡⁣⁢⁣Truthy values are all values that are not falsy. This includes:⁡ true, any non-zero number, any non-empty string, any object, and any array.
    >< In JavaScript, ⁡⁣⁣⁢arrays are a type of object⁡ that can hold multiple values. They are ordered, ⁡⁣⁣⁢mutable⁡, and can contain elements of different types.

 1) Map - creates a new array by applying a function to each element. return values
 2) Filter - creates a new array with all elements that pass the test implemented by the provided function
 3) Reduce - executes a reducer function on each element of the array, resulting in a single output value
 4) forEach - executes a provided function once for each array element. Does not create a new array. but return undefined.

 # Common about all four methods
   - They all take a callback function as an argument.
   - They do not change the original array (they return a new array or value).
   - They can all be chained together.


   -----------------------------------------------------------------

1) ⁡⁣⁢⁣𝗠𝗮𝗽⁡
    - ⁡⁣⁣⁢creates a new array by applying a function to each element⁡
    * use when you want to transform data
    - does not modify the original array
    - compuslary return a value for each element
    - map away return values
    - can be chained with other array methods

    ex-
        ⁡⁢⁢⁢let arr = [1, 2, 3, 4];
        let newArra = arr.map(num => num * 2);
        console.log(newArr); // [2, 4, 6, 8]⁡

2) ⁡⁣⁢⁣𝗙𝗶𝗹𝘁𝗲𝗿⁡
    - ⁡⁣⁣⁢creates a new array with all elements that pass the test implemented by the provided function⁡
    * use when you want to filter data based on a condition
    - does not modify the original array
    - compuslary return a boolean value for each element
    - can be used to filter data
    - can be chained with other array methods

    ex-
        ⁡⁢⁢⁢let arr = [1, 2, 3, 4];
        let newArr = arr.filter(num => num % 2 === 0);
        console.log(newArr); // [2, 4]⁡

3) ⁡⁣⁢⁣𝗥𝗲𝗱𝘂𝗰𝗲⁡
    - ⁡⁣⁣⁢executes a reducer function on each element of the array, resulting in a single output value⁡
    * use when you want to reduce an array to a single value (e.g., sum, product)
    - does not modify the original array
    - compuslary return a single value
    - can be used to reduce an array to a single value
    - can be chained with other array methods

    ex-
        ⁡⁢⁢⁡⁢⁢⁢let arr = [1, 2, 3, 4];
        let sum = arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
        console.log(sum); // 10⁡


4) ⁡⁣⁢⁣𝗳𝗼𝗿𝗘𝗮𝗰𝗵⁡
    - ⁡⁣⁣⁢executes a provided function once for each array element⁡
    * Used when you want to perform an action for each element (e.g., logging)
    - does not modify the original array
    - does not return a new array
    - ⁡⁣⁣⁢does not create a new array⁡
    - is often used for side effects (e.g., logging)

    ex-
        ⁡⁢⁢⁢let arr = [1, 2, 3, 4];
        arr.forEach(num => {
            console.log(num * 2);
        });⁡


    • ⁡⁢⁣⁣𝗳𝗼𝗿𝗘𝗮𝗰𝗵 𝘃𝘀 𝗺𝗮𝗽⁡
        - forEach is used for side effects (e.g., logging), while map is used for transforming data.

        - forEach does not return a new array, while map returns a new array with the transformed elements.

        - forEach can be used with any type of function, while map requires a specific ⁡⁣⁣⁢return value for each element.⁡

        - forEach is generally used when you want to perform an action for each element, while map is used when you want to create a new array based on the original array.

## Practicle use case of both
    a) forEach:-    
        - Logging each element of an array to the console.
        - Updating the DOM for each item in a list.
        - Performing side effects, such as sending data to an API for each element.
    b) map:-
        - Transforming an array of numbers by multiplying each element by 2.
        - Extracting a specific property from an array of objects (e.g., getting an array of names from an array of user objects).
        - Creating a new array of elements based on the original array (e.g., creating an array of JSX elements in React based on an array of data).
